## BAGIAN 12 — Winning & losing formula

**Winning formula (10)**
1. Jika iklan sudah ≥5 chat DAN CPR ≤ Rp39rb MAKA tetap jalan → CPR rata-rata Rp31rb. ✓ — 800 iklan. Pengecualian: tidak dihitung per hari.
2. Jika penempatan WA Status DAN IG Reels dibuka MAKA CPR Rp27–34rb. ✓ — 7 akun. Pengecualian: Nida Reels Rp58,5rb.
3. Jika creative = post winner dipakai ulang DAN teks By Saudia MAKA CPR ±Rp34rb. ~ — 1.101 iklan. Pengecualian: post lama tanpa By Saudia dilarang aturan.
4. Jika paket 9 Hari Januari DAN gambar januari_/saudia_9_hari MAKA CPR Rp38–41rb. ~ — 672 iklan.
5. Jika ad set ≤3 iklan DAN CBO MAKA CPR ≤ Rp39,3rb. ~ — 547 grup.
6. Jika iklan spend ≥ Rp100rb DAN sudah ≥3 chat MAKA CPR akhir ≤ Rp42,6rb. ✓ — 456 iklan.
7. Jika frequency ad set 1,6–2,0 DAN CPR < Rp40rb MAKA belum perlu refresh. ~ — Rp77 jt spend.
8. Jika usia 25–34 DAN laki-laki MAKA CPR Rp35,4rb (termurah). ~ — 353 chat.
9. Jika blok jam 20–23 MAKA CPR Rp36rb. ? — beda kecil.
10. Jika campaign salinan dari winner (bukan dari nol) MAKA peluang winner < Rp15rb. ? — 3 akun, Mar–Apr.

**Losing formula (10)**
1. Jika paket LAT MAKA CPR Rp59rb DAN chat/klik 8,8%. ✓ — 601 iklan.
2. Jika creative testimoni MAKA CPR Rp64rb meski CTR 1,15%. ~ — 89 iklan.
3. Jika objective lead form MAKA Rp121,8rb/lead. ? — 74 lead.
4. Jika objective reach/profile visit/ad recall MAKA 0 chat (Nida Rp151,9 jt). ✓.
5. Jika ad set budget sendiri ≤ Rp50rb/hari MAKA CPR Rp79rb. ~ — 172 chat.
6. Jika iklan Rp20–35rb DAN 0 chat MAKA 74% tetap 0 sampai berhenti. ✓ — 1.657 iklan (catat: banyak dihentikan manual).
7. Jika IG Feed porsi terbesar MAKA CPR Rp45rb (vs Reels Rp34rb). ~ — 7/9 akun.
8. Jika frequency > 2,0 MAKA CPR Rp46,6rb (+43%). ? — data kecil.
9. Jika usia 45–54 perempuan MAKA CPR Rp51rb. ~ — 729 chat.
10. Jika iklan baru dibuat Okt 2026 MAKA CPR Rp48rb (vs winner lama Rp31rb). ✓ — 1.894 iklan.
